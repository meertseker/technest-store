# Script 4: Devices, and "Fits these devices"

- **Length:** about 5 minutes
- **You need:** your phone or laptop, logged in to admin.technest.co.uk; a test product (for example a phone case); the name of one new phone model to add (use a made-up test model and delete it afterwards).
- **Status:** Draft written from the brief - verify every step against the final UI before recording.

---

### Scene 1 (0:00-0:40) Why devices matter

**On screen:** the website on your phone. Pick a phone in the device picker. Show that the shop now only shows accessories for that phone.

**Say:** "On our website, customers pick their phone or console once. After that, they only see things that fit it. That only works if two lists are right: the list of devices, and the devices linked to each product. Both are in the admin."

### Scene 2 (0:40-1:30) The Devices page

**On screen:** sidebar, tap **Devices**. Show the list grouped by brand, then series, then model (for example Apple, then iPhone 16, then iPhone 16 Pro). Use the search box to find "16 pro".

> ⚠ Verify against the final UI

**Say:** "Tap Devices in the menu. Devices are grouped in three levels. First the brand, like Apple or Samsung. Then the series, like iPhone 16. Then the model, like iPhone 16 Pro. Use the search box to find one quickly."

### Scene 3 (1:30-2:45) Add a new model

**On screen:** tap the button to add a device. Fill in: brand, series, model, type (phone, tablet, console or laptop), release year. Add two aliases, for example "16 pro" and the model number from the box. Save.

> ⚠ Verify against the final UI

**Say:** "When a new phone comes out, add it here. Tap to add a device. Type the brand, the series and the model name, exactly as the maker writes it. Choose the type: phone, tablet, console or laptop. Add the year it came out, so newest phones show first. Then aliases. Aliases are other words customers might type, like '16 pro', or the model number printed on the back or on the box. They help people find their phone in search. Then save."

### Scene 4 (2:45-3:15) Edit or delete

**On screen:** open the test model. Change an alias. Save. Then show the delete button, and delete the test model.

> ⚠ Verify against the final UI

**Say:** "To fix a mistake, open the device, change it and save. Be careful with delete. Deleting a device also removes it from every product it was linked to. Only delete a device you added by mistake."

### Scene 5 (3:15-4:30) "Fits these devices" on a product

**On screen:** **Products** in the sidebar, open the test case. Scroll to **Fits these devices**. Search "16", tick iPhone 16 and iPhone 16 Plus. Add a note on one, for example "Not compatible with MagSafe". Save. Remove one device.

> ⚠ Verify against the final UI

**Say:** "Now open a product. Scroll to Fits these devices. Search for the model and tick every device this product really fits. You can add a short note to a device, like 'Not compatible with MagSafe' or 'Slim case only'. Customers see the note on the website. To remove a device, untick it. Then save. If you're not sure a product fits, don't tick it. A wrong fit means a return and an unhappy customer."

### Scene 6 (4:30-5:00) Wrap up

**Say:** "So: keep the Devices list up to date when new phones come out, and on every product tick only the devices it really fits. Quick Add asks you for devices too, so most of the time you do it there."

---

## Common mistakes / if something goes wrong

- **Error when adding a device**: the device probably already exists. Every device has a short web name (for example `iphone-16-pro`) that must be unique. Search for it first.
  > ⚠ Verify against the final UI (exact message)
- **A customer can't find their phone**: add the words they typed as an alias, for example a model number.
- **A product doesn't show for a phone**: open the product and check Fits these devices. Also check the product is published.
- **Deleted a device by mistake**: add it again, then link it again on each product. Links are not restored automatically.

## Rules to remember

- Only link devices the product really fits.
- Use the maker's model name, and put other names in aliases.
- Deleting a device removes it from all products.
