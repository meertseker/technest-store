# Tech Nest Online: owner guides

These guides are for the shop owner. They show how to run the online shop from the admin at
**admin.technest.co.uk**, on a phone or a laptop.

On a phone, open the menu with the button at the top left. The Tech Nest pages are in that
left-hand menu (the sidebar).

A Turkish copy of every file is in [`tr/`](./tr/README.md).

## How to use the scripts

Files 01 to 06 are **screen-recording scripts**. Each one makes a video of about 5 minutes.

1. Open the admin on the device you will use every day (usually your phone).
2. Start a screen recording.
3. Follow the scenes in order. "On screen" says what to tap. "Say" is what to say out loud.
4. Use a **test product** or a **test order**, never a real customer's order.
5. Keep the video. Watch it again when you forget a step.

You can also just read a script as a how-to guide.

## "Verify against the final UI"

These scripts were written **before the admin pages were finished**. They follow the plan for each
page, not the finished screens. So:

- Every step that names a button, a label or a layout has this line under it:

  > ⚠ Verify against the final UI

- Before you record, the person who built the page (or the lead) opens the finished page and checks
  each marked step. If a button has a different name, change the script.
- When a step matches the real screen, delete its marker.
- When a script has no markers left, change its **Status** line to
  "Checked against the final UI on <date>".

Do not record a script that still has markers in it.

## Words used in these guides

- **SKU**: your stock code for a product (for example `CLEAR-CASE-IPHONE-16`).
- **Draft**: a product that is saved but not shown on the website yet.
- **Publish**: make a product visible on the website.
- **Add-on item**: a £1 or low-price item. It can go in any basket, but it can't be a delivery order on its own.
